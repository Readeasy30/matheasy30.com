# Cross-Device Standards

These standards apply to MathEasy30, ReadEasy30, PetNeeds.ai, and all future websites.

## Mission

Every website must work well on:

- small phones
- large phones
- tablets
- laptops
- desktop computers
- large monitors
- touchscreen devices
- smart TVs and TV browsers when practical

## Core Rule

Design mobile-first, then expand upward.

The site should never depend on a perfect screen size.

## Required Screen Support

### Small phones

Target width:

- 320px and up

Requirements:

- large readable text
- full-width buttons
- no horizontal scrolling
- simple navigation
- tap targets easy to press

### Large phones

Target width:

- 390px and up

Requirements:

- comfortable spacing
- readable cards
- visible main action button
- no clutter

### Tablets

Target width:

- 768px and up

Requirements:

- wider cards
- balanced spacing
- simple two-column layouts only when helpful

### Laptops and desktops

Target width:

- 1024px and up

Requirements:

- centered content
- readable line lengths
- professional layout
- strong visual hierarchy

### Large monitors and TVs

Target width:

- 1440px and up

Requirements:

- max-width wrappers
- large readable text
- avoid tiny controls
- avoid stretched content

## Accessibility Rules

Every site should include:

- readable font sizes
- strong color contrast
- large buttons
- simple navigation
- keyboard-friendly controls
- clear headings
- descriptive link text

## Layout Rules

Use:

- responsive grids
- flexible widths
- max-width containers
- relative font sizing
- simple sections

Avoid:

- fixed-width layouts
- tiny buttons
- cramped text
- hidden important actions
- horizontal scrolling
- cluttered menus

## Testing Checklist

Before considering any page finished, check:

1. Phone width
2. Tablet width
3. Desktop width
4. Large screen width
5. Button tapping
6. Navigation links
7. Form inputs
8. Text readability
9. Page speed
10. No broken routes

## Business Rule

A website that fails on mobile loses users.

A website that feels calm and easy on every device earns trust.

## Final Rule

Every project should feel simple, clear, and professional on every screen.
