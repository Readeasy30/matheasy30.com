# MathEasy30 Time Management

## Main rule

Keep building. Do not stop for routine safe updates.

## Work in useful chunks

Each work session should move the site forward in this order:

1. Fix broken files or links.
2. Protect the simple file structure.
3. Improve the app experience.
4. Improve lesson content.
5. Improve support pages.
6. Improve project instructions.
7. Add planning notes for future work.

## Do not waste time on

- repeated planning without edits
- recreating files that already exist
- switching frameworks
- redesigning from scratch
- tiny fragile patches when a clean section update is safer
- asking for approval on normal safe updates

## Stop only for

- blocked tool writes
- private keys or credentials
- payment setup
- live tracking setup
- live monetization setup
- deleting major working code
- changing the tech stack

## Progress rhythm

Make safe commits in small groups.

After several commits, report:

- files changed
- what improved
- what is next
- any blocked item

## Current build priority

1. Keep the 30-day math app stable.
2. Improve mobile UX.
3. Add parent/helper support.
4. Add topic pages.
5. Add printable worksheet planning.
6. Add future monetization only after useful content exists.

## Default action

When unsure, improve the existing simple HTML, CSS, and JavaScript site instead of starting over.
