# MathEasy30 File Map

## Website files

- `index.html`: homepage
- `app.html`: lesson app page
- `app.js`: lesson logic and progress behavior
- `css/style.css`: main style file
- `about.html`: about page
- `parent-guide.html`: parent guide
- `math-facts-practice.html`: math facts practice content page
- `pricing.html`: pricing page
- `contact.html`: contact page
- `privacy.html`: privacy page
- `terms.html`: terms page
- `robots.txt`: search file
- `sitemap.xml`: sitemap file

## Project files

- `README.md`: overview and current structure
- `AGENTS.md`: direct work rules
- `AGENT-INSTRUCTIONS.md`: full AI agent instructions
- `FILE-MANAGEMENT.md`: file map
- `LOCKED-CHECKPOINT.md`: latest safe checkpoint
- `PROJECT-STATUS.md`: current status and next queue
- `SEO-CHECKLIST.md`: search checklist
- `LAUNCH-CHECKLIST.md`: launch checklist
- `CONTENT-PLAN.md`: content plan

## Rules

- Use `css/style.css` for styles.
- Use `app.js` for lesson logic.
- Use `index.html` for the homepage.
- Use `app.html` for the lesson app.
- Keep public pages linked through navigation or footer.
- Put shared business planning in `marketing-system`.
- Keep MathEasy30 code in this repository.

## Update pattern

1. Read the current file.
2. Update the right file.
3. Keep the HTML, CSS, and JavaScript setup simple.
4. Commit useful safe changes.
5. Check homepage, app page, buttons, links, and mobile layout after major changes.
