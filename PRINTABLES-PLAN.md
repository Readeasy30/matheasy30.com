# Printable System Plan

## Purpose

Printable activities help learners:

- slow down
- practice away from screens
- repeat skills
- build confidence

## Planned Printables

### Level A
- counting sheets
- number tracing
- bigger/smaller practice
- adding one more

### Level B
- subtraction practice
- skip counting
- pattern sheets
- compare numbers

### Level C
- addition fluency
- multiplication groups
- simple word problems
- review sheets

### Level D
- division practice
- fractions
- multi-step thinking
- review pages

## Parent Helpers

Each printable should include:

- calm instructions
- simple wording
- helper tips
- encouragement phrases

## Long-Term Goal

Create printable packs that support the online lessons and future premium products.
