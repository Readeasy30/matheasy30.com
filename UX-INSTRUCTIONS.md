# MathEasy30 UX Instructions

## Main UX goal

Make MathEasy30 easy, calm, and clear on phones, tablets, and computers.

## UX rules

1. Use large readable text.
2. Use large buttons.
3. Keep each screen simple.
4. Show one main action at a time.
5. Keep lessons short.
6. Use calm coaching messages.
7. Give hints before frustration grows.
8. Keep parent/helper tips visible.
9. Save progress on the device.
10. Make the next step obvious.

## App screen order

1. Back to Home link
2. Page title
3. Day picker
4. Progress bar
5. Bubbles message
6. Question card
7. Answer box
8. Check, Hint, Clear, Next buttons
9. Confidence message
10. Parent/helper tip

## Button rules

- Primary button: next most important action.
- Secondary buttons: helper actions.
- Buttons should work well on mobile.
- Buttons should not be tiny.
- Button text should be plain.

## Lesson UX

Each lesson should include:

- one short topic
- three simple questions
- clear hints
- calm feedback
- a completion message
- next day button

## Do not add

- clutter
- flashing effects
- confusing menus
- tiny text
- long paragraphs
- hard-to-find buttons
- heavy scripts

## Build rule

Keep improving the existing app instead of rebuilding from scratch.
