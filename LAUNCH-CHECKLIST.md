# MathEasy30 Launch Checklist

## Live Site

Primary domain:

- https://matheasy30.com

Important routes:

- /
- /app
- /app.html
- /about.html
- /404.html
- /robots.txt
- /sitemap.xml

## Before Sharing Publicly

Check these items:

1. Homepage loads.
2. Start Math Check button opens the app.
3. /app route loads the app.
4. /app.html route loads the app.
5. Back to Home works.
6. Check Answer button works.
7. Need a Hint button works.
8. Next button works.
9. Placement result appears.
10. Day 1 practice starts.
11. Site works on phone width.
12. HTTPS works.
13. www domain works or redirects.

## Cloudflare Pages Settings

Use:

- Framework preset: None
- Build command: blank
- Build output directory: .

## Development Rules

- Use AI-agent GitHub commits when possible.
- Prefer full-file replacement for code updates.
- Keep static HTML/CSS/JavaScript.
- Do not add React, Vite, or build tools.
- Keep the site live and usable after each change.

## Launch Goal

Launch a useful beta quickly, then improve daily.
