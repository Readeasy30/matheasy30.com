# MathEasy30 AI Agent Workflow

## Project Mission

MathEasy30 helps struggling learners build math confidence slowly, calmly, and safely.

This project is designed especially for:
- struggling learners
- special education learners
- children with math anxiety
- overwhelmed learners
- parents helping children at home

The goal is confidence first, then skill growth.
