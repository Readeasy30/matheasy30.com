# MathEasy30 Lesson Roadmap

## Mission

MathEasy30 helps struggling learners build math confidence through calm, daily practice.

The system grows slowly, clearly, and safely.

---

# Level A

## Focus
- Counting
- Number recognition
- Adding one more
- Comparing small numbers

## Planned Days

### Days 1–5
- Count forward
- Count backward
- Match numbers
- Bigger and smaller
- Add 1

### Days 6–10
- Add 2
- Number lines
- Missing numbers
- Count groups
- Review day

---
